# MonteCristo Archives

Site básico sobre o livro e o filme **O Conde de Monte Cristo**, com informações sobre a história, os personagens e as diferenças entre as duas versões.

## Objetivo

O projeto foi desenvolvido para praticar e aprofundar os conhecimentos de **CSS e JavaScript** adquiridos em cursos, aplicando o aprendizado na construção de um site.

## Tecnologias

- HTML
- CSS
- JavaScript

## Como visualizar

Baixe ou clone o projeto e abra o arquivo `index.html` no navegador ou acesse https://montecristoarchives.vercel.app/
